# 🎭 Demo Mode - Quick Guide

## ✅ Changes Applied

I've fixed the location issue for your demo with these improvements:

### 1. **Increased Timeout** 
- Location request timeout increased from 10s to 20s
- Better chance of getting actual location on slower networks

### 2. **Demo Mode Button** 🎭
- When location fails, you'll see a **"🎭 Use Demo Mode"** button
- Click it to instantly show 8 sample doctors with realistic data
- Perfect for presentations and demos!

### 3. **Better Error Messages**
- Friendly yellow info box instead of harsh red error
- Clear message that location is optional
- Multiple action buttons for different scenarios

### 4. **Three Action Buttons**
When location fails, you get:
- **🔄 Try Again** - Retry location request
- **🎭 Use Demo Mode** - Show sample doctors instantly (perfect for demos!)
- **ℹ️ How to Enable** - Step-by-step guide to enable location

## 🚀 How to Use for Your Demo

1. **Open** http://localhost:3000
2. **Describe symptoms** (e.g., "fever and headache")
3. **Click "Analyze"** - Shows AI predictions
4. **Click "Find Nearby Doctors"**
5. **If location fails** → Click **"🎭 Use Demo Mode"**
6. **Demo doctors appear** instantly with realistic data!
